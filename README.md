# 스마트 평가 센터

휴대폰·태블릿·PC에서 사용하는 반응형 웹앱입니다. **Streamlit 없이 실행합니다.** 기존 Google Sheets의 문제와 학습 기록을 그대로 사용하며, 생성형 AI API와 AI 채점은 사용하지 않습니다.

## 달라진 사용 흐름

- **문제 풀기:** 분야·검색으로 선택 → 한 문제씩 풀이 → 제출 → 정답과 해설 확인
- 미응답이 있으면 제출 전에 문항 수·번호를 안내합니다. 돌아가서 마저 풀거나, 미응답을 오답 처리해 제출할 수 있습니다. 미응답도 전체 문항 수와 오답 노트에 포함됩니다.
- **오답 노트:** 틀린 문제만 다시 풀이. 여러 번 틀린 같은 문제는 한 번에 완료 처리합니다.
- **문제 만들기:** 주제 입력 → 요청문 복사 → 외부 ChatGPT에 붙여넣기 → 답변을 통째로 붙여넣기 → 미리보기 → 관리자 등록
- 초안은 현재 브라우저에 자동 저장됩니다. 새로고침과 관리자 로그인 후에도 유지됩니다.
- 학습 기록, 참여 현황, 성취 순위, 이야기방, 문제 수정, 운영 설정, 백업·복구를 제공합니다.
- **참여 현황:** 퀴즈 그룹, Guest 제외, 모두 미참여인 퀴즈 제외, 참여자만 표시를 지원합니다. 세 제외 조건은 기본으로 켜집니다. 등록만 했거나 점수가 비어 있는 기록은 완료가 아니며 실제 0점 제출은 참여로 인정합니다. 이름에 `test`가 포함되면 항상 제외합니다.

휴대폰에서는 하단 메뉴와 한 열 화면, 태블릿에서는 넓이에 맞는 분할 화면, PC에서는 왼쪽 메뉴와 카드 목록을 사용합니다. 수식 표시 파일도 앱에 포함되어 외부 CDN에 의존하지 않습니다.

## 실행하기

Python 3.12 이상을 사용합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn web_app:app --host 127.0.0.1 --port 8000 --workers 1
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 편의 실행 파일은 `start-web.ps1`입니다. 기존 가상 환경에 Streamlit이 설치되어 있어도 새 실행 경로는 이를 가져오거나 사용하지 않습니다.

## 비공개 연결 설정

`secrets.toml.example`을 복사해 프로젝트 폴더의 `secrets.toml`을 만들고 값을 채웁니다. 이 파일은 Git에서 제외됩니다. 환경 변수로도 같은 키를 설정할 수 있으며, 환경 변수가 우선합니다.

| 항목 | 용도 |
| --- | --- |
| `SHEET_ID` | 기존 Google 스프레드시트 ID |
| `GCP_JSON` | 서비스 계정 JSON을 담은 문자열. 해당 시트의 편집 권한 필요 |
| `ADMIN_PASSWORD` | 문제 등록·운영 관리 비밀번호. 기본 비밀번호 없음 |
| `GS_BACKUP_URL` | 기존 Google Apps Script 백업 주소. 사용하는 경우에만 설정 |
| `SECURE_COOKIE` | HTTPS 운영 서버에서는 `true` |

기존 `.streamlit/secrets.toml`은 새 설정 파일이 없을 때만 호환용으로 읽습니다. **Streamlit 서비스는 필요하지 않습니다.** 새 설정에는 AI API 키를 넣지 않습니다.

저장소 설정이 없어도 문제 요청문 작성과 붙여넣기 미리보기는 사용할 수 있습니다. 문제 등록과 학습 기록 저장은 연결이 필요합니다. 사용자 이름은 기록을 구분하는 값으로, 개인 계정 인증은 아닙니다. 공용 기기에서는 이름을 지우고 사용을 마쳐 주세요.

## 휴대폰과 외부 웹 접속

반응형 화면은 같은 웹앱을 사용합니다. 실제 휴대폰에서 접속하려면 휴대폰이 접근할 수 있는 서버 주소가 필요합니다.

- 이 PC 전용 실행: 위의 `127.0.0.1` 주소를 사용합니다.
- 같은 네트워크 공유를 선택한 경우: 서버를 `--host 0.0.0.0`으로 실행하고 휴대폰에서 `http://PC의내부IP:8000`에 접속합니다. PC가 켜져 있어야 하며 방화벽과 Wi-Fi의 기기 간 접속 허용 여부에 영향을 받습니다. 편의 실행 파일의 `-ShareOnNetwork` 옵션과 같습니다.
- 인터넷 공개: 포함된 `Dockerfile` 또는 같은 Python 실행 명령으로 일반 Python 서버에 배포할 수 있습니다. HTTPS와 서버 비공개 환경 변수를 설정해야 합니다. 운영 환경과 주소는 별도로 정해야 하며 현재 작업은 공개 배포를 수행하지 않습니다.

Docker 이미지는 코드와 정적 파일만 포함하며 비공개 설정과 테스트 데이터를 포함하지 않습니다. 호스팅 비용과 외부 ChatGPT 이용 조건은 선택한 서비스에 따릅니다. 앱 안에서 과금되는 생성형 AI API를 호출하는 코드는 없습니다.

## 운영 특성

- **서버 프로세스는 1개(`--workers 1`)로 실행합니다.** 학습 중인 평가 세션과 관리자 로그인 상태는 서버 메모리에 보관합니다. 서버를 재시작하면 진행 중 평가는 다시 시작해야 합니다. 평가는 기본 24시간, 관리자 인증은 8시간 후 만료됩니다.
- 답을 고르거나 문제를 넘길 때 서버 요청이 발생하지 않습니다. Google Sheets 읽기는 30초 캐시를 사용하고 변경 후 갱신합니다. 시트를 직접 수정하면 캐시 만료 후 반영됩니다.
- 정답은 제출 전 학습자에게 전송하지 않으며 서버에서 채점합니다. 주관식은 공백·대소문자를 정규화해 정해진 정답과 비교합니다. 허용할 여러 정답은 `서울 | Seoul`처럼 `|`로 구분하세요. 서술형 의미 판단은 하지 않습니다.
- 제출 저장이 실패하면 결과 화면에서 같은 평가 ID로 재시도합니다. 결과·오답·상세 로그 시트의 `AttemptID`를 확인해 중복 저장을 막습니다. 기존 열과 추가 열은 보존합니다.
- 문제 제목은 기존 학습 기록과 연결되므로 수정 화면에서 변경할 수 없습니다. 원본 문제가 삭제·변경된 오답은 조용히 숨기지 않고 확인 후 정리할 수 있습니다.
- 기본 메뉴·분야, 추가 분야, 순위 집계 시작일, 상위 표시 인원을 관리 화면에서 설정할 수 있습니다. 시작일 변경은 기록을 삭제하지 않습니다.
- 백업은 기존 Apps Script 설정을 우선 사용합니다. 설정이 없으면 서비스 계정에 사용 가능한 Drive 복사 권한·공간이 필요합니다. 새 접두어 `스마트평가센터_백업_`과 기존 `퀴즈_백업_` 이름을 인식합니다.
- 복구는 선택한 백업 이름을 다시 입력해 확인합니다. 복구 전에 안전 복사본을 만든 후 셀 값을 옮깁니다. 수식·서식 자체는 안전 복사본에 보존되며 복구 대상에는 계산된 셀 값이 들어갑니다. 백업에 없는 현재 탭은 유지합니다. 실패 시 원상 복구를 시도하고 복구 상태를 알립니다.

## 검증

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests_web -v
node --check static/app.js
```

새 웹앱 테스트는 가짜 저장소와 별도 설정을 주입하므로 실제 Google Sheets를 읽거나 쓰지 않습니다. 브라우저에서 가짜 자료로 직접 확인하려면 다음과 같이 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m uvicorn tests_web.browser_fixture:app --host 127.0.0.1 --port 8001
```

이 테스트 서버의 관리자 비밀번호는 `browser-test-only`이며 실제 운영 서버에는 적용되지 않습니다.

`my_study_app.py` 등 이전 Streamlit 파일과 `tests/`는 이전 구현을 비교할 수 있도록 보존했습니다. 새 서버는 `web_app.py`, `web_storage.py`, `web_config.py`, `quiz_core.py`, `prompts.py`, `static/`만 사용합니다. 이전 구현의 확인 지점은 로컬 커밋 `143f88c`입니다.
