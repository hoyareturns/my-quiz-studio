# 스마트 평가 센터

휴대폰·태블릿에서도 퀴즈를 등록하고 풀 수 있는 Streamlit 앱입니다.
앱 내부에서 생성형 AI API를 호출하지 않습니다. 문제 생성과 주관식 AI 채점은 제거했고, Google Sheets는 문제와 학습 기록 저장에 사용합니다.

## 실행

Python 3.12에서 검증했습니다. 새 환경에서는 다음과 같이 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run my_study_app.py
```

현재 작업 폴더의 개발 환경은 기존 PC 패키지를 재사용하도록 만들었습니다. 재현 가능한 새 환경은 위 명령으로 별도로 구성할 수 있습니다.

## 연결 설정

`.streamlit/secrets.toml.example`을 참고해 `.streamlit/secrets.toml`을 작성하거나 Streamlit 배포 환경의 Secrets에 설정합니다. 실제 비밀값은 Git에 올리지 않습니다.

- `GCP_JSON`: Google 서비스 계정 JSON을 담은 문자열
- `SHEET_ID`: 문제·기록을 저장할 Google 스프레드시트 ID. 해당 서비스 계정에 편집 권한이 필요합니다.
- `ADMIN_PASSWORD`: 새 관리자 비밀번호. 기존 코드에 노출됐던 비밀번호는 더 이상 사용하지 않습니다.
- `GS_BACKUP_URL`: 기존 Apps Script 백업 기능을 사용할 때만 필요한 주소

연결 설정 없이도 **문제 등록 → 요청문 만들기·미리보기**는 이용할 수 있습니다. 실제 등록·성적 저장은 연결 설정 후 가능합니다. 관리자 인증은 문제 등록 메뉴와 관리 메뉴에서 할 수 있습니다.

기존 `GEMINI_API_KEY`는 필요하지 않습니다. 이 변경은 외부 Google 계정의 API 키나 청구 설정을 변경하지 않으므로, 다른 앱에서 쓰지 않는 키는 계정에서 별도로 폐기할 수 있습니다.

## 휴대폰·태블릿에서 문제 등록

1. **문제 등록** 메뉴의 **GPT에 보낼 요청문 만들기**를 엽니다.
2. 주제·문제 수·유형·난이도·참고 내용을 정하고 요청문을 만듭니다.
3. 요청문 오른쪽 위 복사 버튼을 누르고 ChatGPT에 직접 붙여넣습니다.
4. ChatGPT 답변을 복사해 앱의 **문제 붙여넣기**에 넣습니다.
5. 제목·분류를 입력하고 **문제 미리보기**에서 모든 문제의 정답과 해설을 검토합니다.
6. 관리자 인증 후 **퀴즈 등록**을 누릅니다.

외부 ChatGPT는 해당 계정의 요금제를 따릅니다. 앱에서 자동으로 요청하거나 요금을 발생시키는 AI API 연결은 없습니다.

붙여넣은 초안은 같은 브라우저 세션에서 메뉴를 이동해도 유지됩니다. 브라우저 새로고침·종료 후에는 유지되지 않으므로 긴 작업은 별도로 보관하세요.

## 문제 형식과 채점

```text
[Q1] 대한민국의 수도는?
[O] ① 서울 ② 부산 ③ 대전
[A] ①
[K] 수도
[E] 대한민국의 수도는 서울입니다.

[Q2] 대한민국의 수도를 쓰세요.
[O] 주관식
[A] 서울 | Seoul
[K] 수도
[E] 서울입니다.
```

- `[Q]`, `[Q1]` 형식을 모두 지원합니다. 숫자 보기 `1.`, `2.`는 각각 새 줄에 쓰면 됩니다.
- 주관식은 공백·대소문자를 정규화하고 등록한 정답과 비교합니다. 추가 정답은 `|`로 구분하세요.
- `0/FALSE/거짓`, `1/TRUE/참`은 같은 논리값으로 취급합니다. 분수와 수식을 잘라서 부분 정답으로 인정하지 않습니다.
- 예전 단어형 `서울/Seoul` 표기는 지원하지만, 괄호나 쉼표를 이용한 암묵적 동의어 분리는 하지 않습니다. 기존 문제의 복수 정답은 `|`로 정리하세요.
- 문제 전체를 검사하며, 보기·정답이 잘못되거나 일부 문제가 누락되면 등록을 막고 문제 번호를 표시합니다.
- 제목은 기존 기록의 연결 기준이므로 수정 화면에서 변경하지 않습니다. 원본 질문이 바뀐 기존 오답은 변경 사실을 보여주고 사용자가 정리할 수 있습니다.

## 저장과 속도

- 화면에 필요한 데이터를 선택적으로 읽고, 문제·설정 60초 / 성적·오답 30초 동안 조회 결과를 재사용합니다.
- 사용자가 저장한 데이터는 즉시 관련 캐시를 비웁니다. 다른 사용자 변경은 캐시 유효 기간 뒤 또는 도움말의 **최신 데이터 불러오기**로 반영됩니다.
- 퀴즈 답안은 폼으로 한 번에 제출합니다. 관리자 백업 목록은 요청할 때만 조회합니다.
- 오답 여러 개는 한 요청에 묶어 저장합니다. 기존에 중복 기록하던 잘못된 형식의 오답 행은 새로 만들지 않습니다. 과거 행은 자동 삭제하지 않습니다.
- 제출 재시도 시 중복 기록을 줄이기 위해 `Results`, `WrongAnswers`, `WrongAnswers_Logs` 시트 끝에 `AttemptID` 열을 자동 추가합니다. 기존 열과 행을 유지하며, 참여 현황은 열 이름으로 읽습니다.
- 저장이 완료되지 않으면 결과 화면에 안내하고 재시도할 수 있습니다. 저장 확인 전에 화면을 새로고침하지 마세요.

## 검증

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
```

테스트는 Google API 경계에서 대체 저장소를 사용하며 운영 데이터에 접속하지 않습니다. 실제 서비스 계정 권한, 기존 시트 구조, 외부 백업 스크립트와 실사용 응답 시간은 연결 환경에서 별도로 확인해야 합니다.

학습자 이름은 기록 구분용이며 본인 인증을 제공하지 않습니다. 운영 배포는 저장소 수정과 별도입니다.
