스마트 평가 센터 — 사용 및 운영 안내

직원 공유 주소 (회사 안·밖 공통)
https://valley-unfrozen-chalice.ngrok-free.dev

1. 위 주소를 휴대폰·PC 브라우저에서 엽니다.
2. 처음 ngrok 안내가 나오면 Visit Site를 누릅니다.
3. 접속 비밀번호 없이 이름을 입력하고 문제를 풉니다.
4. 제출 직후 정답·점수·해설을 확인할 수 있습니다.
5. 오답 노트·학습 기록·성취 순위·이야기 나누기는 누구나 이용합니다.
6. 문제 만들기·참여 현황·관리는 관리자 로그인 후 이용합니다.
7. 이름은 같은 기기·브라우저·주소에서 유지됩니다. 다른 주소나 브라우저에서는 다시 설정하세요.

서버 운영
- 현재 이 PC에서 교육 서버와 ngrok 연결이 백그라운드로 실행됩니다.
- PC 재부팅 후 Windows에 로그인하면 약 30초 뒤 자동으로 시작됩니다.
  교육 서버와 외부 연결을 함께 켜며, 이미 실행 중이면 중복 실행하지 않습니다.
- 수동으로 다시 켜려면 '외부접속 시작.cmd'를 더블클릭하세요.
- 브라우저는 닫아도 됩니다. PC는 켜 두고 절전 모드로 전환하지 마세요.
- 재시작하면 진행 중인 문제풀이와 관리자 로그인은 초기화됩니다.
  Google Sheets에 저장된 제출 결과는 유지됩니다.

참고
- ngrok 무료판의 사용량 제한이 적용됩니다. 유료 결제를 설정하지 않았습니다.
- 이름 입력은 직원 본인 인증이 아닙니다. 동명이인은 부서나 사번을 붙여
  동일한 이름으로 사용하세요.
- 주소를 전달받은 외부인도 문제를 보고 응시할 수 있는 공개 학습 방식입니다.
- 계정 연결 인증키는 .cache/ngrok/agent.yml에 보관되고 Git에는 포함되지 않습니다.

자동 시작 설정
- Windows 작업 스케줄러: SmartQuiz-ExternalAccess-Autostart
- 현재 Windows 사용자 로그인 시 실행됩니다. 로그인 전에는 실행되지 않습니다.
- 네트워크 연결이 늦으면 30초 간격으로 최대 5회 시도합니다.
- 실행 기록: artifacts/automatic-start.log
- 자동 시작 해제: 작업 스케줄러에서 위 작업을 사용 안 함으로 변경합니다.

휴대폰 홈 화면에 앱 추가
- QR코드로 접속한 뒤 상단 ‘앱 설치’를 누르세요.
- 안드로이드: Chrome 메뉴 → 앱 설치 또는 홈 화면에 추가.
- 아이폰: Safari 공유 메뉴 → 홈 화면에 추가 → 추가.
- 다음부터 홈 화면 아이콘으로 접속할 수 있습니다. 인터넷과 교육 서버 실행이 필요합니다.
- 설치한 앱에서 처음 한 번 이름을 다시 입력해야 할 수 있습니다.

관리자 이름
- 관리자 로그인 시 자동으로 ‘관리자’ 이름을 사용합니다.
- 로그아웃하면 로그인 전에 설정한 학습자 이름으로 돌아갑니다.
- 일반 사용자는 ‘관리자’ 이름을 설정하거나 해당 이름으로 글·기록을 남길 수 없습니다.
